Модуль 01

Многопоточность (Threading)

Когда один поток не справляется — запускаешь несколько. Но не всё так просто из-за GIL.

🧵 Что такое поток?

Поток — это линия выполнения внутри процесса. Представь кухню: один повар (процесс) может варить суп, резать салат и ставить чайник — последовательно. А три повара (потока) делают это одновременно.

Аналогия из .NET

Если ты знаешь C#: Task.Run() — это примерно то же самое, что threading.Thread. Только в Python всё через модуль threading, а не через System.Threading.

🔒 GIL — Great Interceptor of Threads

GIL (Global Interpreter Lock) — мьютекс, который не даёт двум потокам выполнять Python-код одновременно в одном процессе.

Поток 1
работает
→
GIL
заблокирован
→
Поток 2
ждёт
Ключевое: GIL отпускается при I/O-операциях (сеть, файл, БД, time.sleep). Поэтому потоки отлично работают для I/O-bound задач.
Плохо: Если ты считаешь.factorial в 10 потоков — ускорения НЕ будет. GIL не даст. Для CPU-bound нужен multiprocessing.

🔐 Lock — защищаем общую переменную

Когда два потока пишут в одну переменную — происходит гонка (race condition). Результат непредсказуем.

# Без lock — гонка
global counter
counter += 1  # атомарная операция? НЕТ!
# Поток 1 читает counter=5
# Поток 2 читает counter=5
# Оба пишут 6
# Итого: 6 вместо 7

# С lock — безопасно
with lock:
    counter += 1  # только один поток за раз

В C# это lock (obj) { ... } или Mutex. В Python — threading.Lock().

⚡ ThreadPoolExecutor — пул потоков

Создавать потоки вручную — мучение. Пул переиспует N потоков для M задач. Отправил 100 запросов — 4 потока обработали по 25.

from concurrent.futures import ThreadPoolExecutor

def fetch(url):
    # эмулирует запрос к API (0.5 сек)
    time.sleep(0.5)
    return f"данные из {url}"

urls = ["url1", "url2", "url3", "url4"]

# Последовательно: 4 × 0.5 = 2 сек
results = [fetch(u) for u in urls]

# В пуле: ~0.5 сек (параллельно!)
with ThreadPoolExecutor(max_workers=4) as pool:
    results = list(pool.map(fetch, urls))
Аналогия из .NET

ThreadPoolExecutor ≈ Task.WhenAll + Parallel.ForEach. Пул потоков есть везде — и в .NET, и в Java, и в Go (goroutines).

🚦 Event — синхронизация потоков

Event позволяет потокам ждать сигнала от другого потока.

import threading

event = threading.Event()

def waiter(name):
    print(f"  {name}: жду сигнал...")
    event.wait()  # блокируемся пока не set()
    print(f"  {name}: пошёл!")

# 3 потока ждут
threads = [threading.Thread(target=waiter, args=(f"t-{i}",)) for i in range(3)]
[...t.start() for t in threads]

time.sleep(0.3)
event.set()  # все 3 потока просыпаются!
Модуль 02

Асинхронность (async/await)

Не потоки, не процессы — отдельная модель. Один поток, Thousands of задач, cooperative multitasking.

🌀 Что такое async/await?

Async — это кооперативная многозадачность. Один поток переключается между задачами, когда одна ждёт (I/O, сеть, таймер). Не переключается, пока выполняет код.

Корутина A
работает
→
await
отдаёт управление
→
Корутина B
работает
Простым языком: Thread = отдельный повар. Async = один повар, который ставит чайник и пока ждёт режет салат. Не стоит без дела — переключается на другую задачу.

🪆 Async-замыкания

Замыкание — функция, которая захватывает переменные из внешней области видимости. Async-замыкание — та же штука, но является корутиной.

def make_filter(min_score):
    # _cache — захваченная переменная
    _cache = []

    async def filter_users(users):
        nonlocal _cache
        if not _cache:
            await asyncio.sleep(0.01)  # I/O pause
            _cache = [u for u in users if u.score >= min_score]
        return _cache

    return filter_users  # возвращаем корутину

# Использование:
high_scorers = make_filter(min_score=8.0)
result = await high_scorers(users)  # вызываем как корутину
Аналогия из .NET

Замыкание в Python — это как лямбда в C#, которая захватывает переменную из внешнего метода. async ≈ async Task<T>.

🗄️ SQLAlchemy ORM — параллельные запросы

SQLAlchemy — стандарт ORM для Python. Работает через движок (engine) и сессии (session). Под капотом отправляет SQL, но ты работаешь с объектами.

Аналогия из .NET

AsyncSession ≈ DbContext в EF Core. select(User) ≈ LINQ dbContext.Users.Where(...). engine ≈ DbConnection.

from sqlalchemy import Column, Integer, String, Float, select
from sqlalchemy.ext.asyncio import AsyncSession, create_async_engine

# Модель — как C# entity class
class User(Base):
    __tablename__ = "users"
    id    = Column(Integer, primary_key=True)
    name  = Column(String(50))
    score = Column(Float, default=0.0)

# Движок — как connection string
engine = create_async_engine("sqlite+aiosqlite:///db.sqlite")
session_factory = async_sessionmaker(engine)

# Запрос — как LINQ
async def fetch_users(min_score):
    async with session_factory() as session:
        stmt = select(User).where(User.score >= min_score)
        result = await session.execute(stmt)
        return result.scalars().all()

# 3 запроса ПАРАЛЛЕЛЬНО
results = await asyncio.gather(
    fetch_users(5.0), fetch_users(8.0), fetch_users(9.5),
)

🔗 Ленивые вычисления (async-генераторы)

Ленивые вычисления — данные обрабатываются по мере необходимости, а не все сразу. Экономит память.

async def lazy_map(iterable, fn):
    """Применяет fn к каждому элементу при итерации."""
    async for item in iterable:
        yield fn(item)

async def lazy_filter(iterable, predicate):
    """Отдаёт только те, где predicate = True."""
    async for item in iterable:
        if predicate(item):
            yield item

# Пайплайн: БД → map(×2) → filter(≥16) → список
stream = fetch_users_stream()
doubled = lazy_map(stream, lambda u: u.score * 2)
filtered = lazy_filter(doubled, lambda s: s >= 16.0)

results = [s async for s in filtered]  # вот тут данные ЧИТАЮТСЯ
Важно: Пока нет async for — данные не читаются. Это как IEnumerable / yield return в C#.

📝 CRUD: Create → Read → Update → Delete

Полный цикл работы с данными через SQLAlchemy session.

async with session_factory() as session:
    # CREATE — добавляем объект
    user = User(name="Алиса", email="alice@mail.com", score=95.5)
    session.add(user)
    await session.commit()

    # READ — достаём по id
    await session.refresh(user)
    print(user.name)  # Алиса

    # UPDATE — меняем атрибуты
    user.score = 100.0
    user.name = "Алиса Великая"
    await session.commit()

    # DELETE — удаляем
    await session.delete(user)
    await session.commit()

📊 Агрегации и Raw SQL

SQLAlchemy умеет COUNT, AVG, SUM, MIN, MAX и raw SQL.

from sqlalchemy import func, text

async with session_factory() as session:
    # COUNT
    count = (await session.execute(
        select(func.count(User.id))
    )).scalar()
    print(f"всего: {count}")

    # AVG + MIN + MAX
    avg = (await session.execute(
        select(func.avg(User.score))
    )).scalar()

    # RAW SQL — когда ORM не хватает
    result = await session.execute(
        text("SELECT name, score FROM users WHERE score > 90")
    )
    for name, score in result.all():
        print(f"  {name}: {score}")

🔗 Связи: один-ко-многим

Как внешние ключи в БД, но на уровне объектов. User → Orders.

class User(Base):
    # ...
    orders = relationship("Order", back_populates="user")

class Order(Base):
    # ...
    user_id = Column(Integer, ForeignKey("users.id"))
    user = relationship("User", back_populates="orders")

# Создаём с связями
user = User(name="Борис")
user.orders = [Order(product="Ноутбук", amount=999.99)]

# Читаем обратно — SQLAlchemy подгружает автоматически
for order in user.orders:
    print(order.product)  # Ноутбук

💳 Транзакции: commit / rollback

Если ошибка — откатываем. Если ок — коммитим. Как в банковском переводе.

async with session_factory() as session:
    # Успешная транзакция
    async with session.begin():
        session.add(User(name="OK"))
    print("COMMIT")

    # Откат при ошибке
    try:
        async with session.begin():
            session.add(User(name="FAIL"))
            raise ValueError("что-то пошло не так")
    except ValueError:
        print("ROLLBACK")
Модуль 03

Мультипроцессы (Multiprocessing)

Когда потоки не помогают (GIL) — запускаешь отдельные процессы. Каждый — свой Python, свой GIL.

🏗️ Процесс vs Поток

Поток — одна нить в одном процессе. Делят память. Процесс — отдельный Python со своей памятью. Не делят ничего.

🧵 Поток (threading)

• Делит память
• GIL блокирует параллелизм
• Лёгкий (мало памяти)
• Для I/O-bound задач

⚙️ Процесс (multiprocessing)

• Своя память
• Каждый процесс — свой GIL
• Тяжёлый (много памяти)
• Для CPU-bound задач

🏊 Pool — пул процессов

Аналог ThreadPoolExecutor, но для процессов.

from multiprocessing import Pool
import time

def heavy_compute(n):
    """Тяжёлое вычисление — 10M операций."""
    return sum(i * i for i in range(n))

data = [10_000_000] * 4

# Последовательно: ~4 сек
result_seq = [heavy_compute(x) for x in data]

# 4 процесса: ~1 сек (реальный параллелизм!)
with Pool(processes=4) as pool:
    result_par = pool.map(heavy_compute, data)

# Ускорение ≈ 4x (на 4 ядрах)
GIL обойдён: Каждый процесс — отдельный интерпретатор Python со своим GIL. 4 ядра = 4 GIL = реальный параллелизм.

🤝 Shared Memory — общая память

Процессы не делят память по умолчанию. Но можно явно выделить общий кусок через Array и Value.

from multiprocessing import Process, Array, Value

def increment(shared_array, index, value):
    with shared_array.get_lock():  # без lock — гонка!
        shared_array[index] += value

shared = Array("i", [0, 0, 0, 0])  # 4 int

procs = [Process(target=increment, args=(shared, i, 100))
         for i in range(4)]
[...p.start() for p in procs]
[...p.join() for p in procs]

print(list(shared))  # [100, 100, 100, 100]

📬 Pipe и Queue — обмен данными

Процессы не могут просто так передавать данные. Используют Pipe (точка-точка) или Queue (очередь).

Pipe

• Два конца: parent + child
• Простая передача
• Быстрее Queue
• Только 2 участника

Queue

• FIFO очередь
• Производитель-потребитель
• Много producers/consumers
• Thread-safe

# Producer-Consumer через Queue
def producer(queue, n):
    for i in range(n):
        queue.put(i * i)
    queue.put(None)  # стоп-сигнал

def consumer(queue, results):
    total = 0
    while True:
        item = queue.get()
        if item is None: break
        total += item
    results.append(total)
Модуль 04

Comprehensions

Питоновий синтаксис для создания коллекций одной строкой. Читабельнее, быстрее, короче.

📋 List comprehension

Создать список за одну строку вместо цикла из 4 строк.

❌ Цикл

result = []
for x in range(10):
    if x % 2 == 0:
        result.append(x ** 2)

✅ Comprehension

result = [x ** 2 for x in range(10)
          if x % 2 == 0]
# С условием + else
labels = ["чёт" if x % 2 == 0 else "нечёт" for x in range(6)]
# ['чёт', 'нечёт', 'чёт', 'нечёт', 'чёт', 'нечёт']

📖 Dict comprehension

# Буква → ASCII код
ascii_map = {chr(i): i for i in range(ord("a"), ord("g") + 1)}
# {'a': 97, 'b': 98, ..., 'g': 103}

# Фильтрация словаря
scores = {"Алиса": 95, "Борис": 67, "Глеб": 42}
passed = {k: v for k, v in scores.items() if v >= 60}
# {'Алиса': 95, 'Борис': 67}

🔋 Generator comprehension

Ленивый — элементы генерируются по одному, не хранятся в памяти.

# () вместо [] — это генератор
total = sum(x ** 2 for x in range(1_000_000))
# Не создаёт список из 1M элементов!
# Считает сумму на лету.
Экономия памяти: [x**2 for x in range(M)] хранит M чисел. (x**2 for x in range(M)) хранит 0 чисел — вычисляет по одному.

Russian dolls Вложенные comprehension

matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

# Разворачиваем матрицу в плоский список
flat = [num for row in matrix for num in row]
# [1, 2, 3, 4, 5, 6, 7, 8, 9]

# Транспонирование
transposed = [[row[i] for row in matrix] for i in range(3)]
# [[1, 4, 7], [2, 5, 8], [3, 6, 9]]

🥜 Walrus operator (:=)

Присваивает значение внутри выражения. Python 3.8+.

# Без walrus: вычисляем len дважды
for word in ["hi", "hello", "hey"]:
    if len(word) > 2:
        print(word, len(word))

# С walrus: вычисляем один раз
result = [(word, length)
          for word in data
          if (length := len(word)) > 2]

🏎️ Бенчмарк: что быстрее?

# Результат на 10K элементов × 100 итераций:
# цикл:          1.00x (базовый)
# comprehension: 1.3x быстрее
# map+filter:    1.1x быстрее

# Comprehension = самый читабельный И быстрый вариант

Tricky Questions

Ловушки, подводные камни и собеседованные вопросы по Python. Знание этих штук — уровень Senior.

🪤 #1 Mutable Default Argument

Самая famous ловушка Python. Default argument вычисляется ОДИН раз при определении функции.

❌ Баг

def append(num, target=[]):
    target.append(num)
    return target

append(1)  # [1]
append(2)  # [1, 2] — БАГ!
append(3)  # [1, 2, 3] — БАГ!

✅ Фикс

def append(num, target=None):
    if target is None:
        target = []
    target.append(num)
    return target

append(1)  # [1]
append(2)  # [2] — РАБОТАЕТ!

⏰ #2 Late Binding Closures

Замыкания захватывают переменную, а не её значение. Вызов происходит после завершения цикла.

❌ Баг

funcs = []
for i in range(5):
    funcs.append(lambda: i)

[f() for f in funcs]
# [4, 4, 4, 4, 4] — БАГ!
# i = 4 ко времени вызова

✅ Фикс

funcs = []
for i in range(5):
    funcs.append(lambda i=i: i)
    #    ^^^ default arg захватывает ТЕКУЩЕЕ значение

[f() for f in funcs]
# [0, 1, 2, 3, 4] — РАБОТАЕТ!

🔬 #3 Float точность

0.1 + 0.2 != 0.3 — это не баг Python, это IEEE 754.

print(0.1 + 0.2)             # 0.30000000000000004
print(0.1 + 0.2 == 0.3)      # False

# Фикс:
from decimal import Decimal
Decimal("0.1") + Decimal("0.2") == Decimal("0.3")  # True

# Для денег: копейки, НЕ float
price = 1500  # 15.00 руб

📋 #5 Shallow vs Deep copy

❌ Shallow copy

original = [[1, 2], [3, 4]]
shallow = original.copy()

shallow[0][0] = 99
# original[0][0] ТОЖЕ 99!
# Копия ссылок, а не значений

✅ Deep copy

import copy
original = [[1, 2], [3, 4]]
deep = copy.deepcopy(original)

deep[0][0] = 99
# original[0][0] = 1 — НЕ изменился!

Модуль 06

Метаклассы

Классы, экземплярами которых являются другие классы. Фабрики для создания типов. Самая мощная и опасная фича Python.

🏭 type() — фабрика классов

Всё в Python — объект. Даже класс. type(MyClass) → type. Метакласс по умолчанию.

# Обычный класс:
class Hello:
    greeting = "привет"

# То же самое через type():
Hello = type("Hello", (), {"greeting": "привет"})

# type(name, bases, namespace)
#   name     — имя класса
#   bases    — базовые классы (кортеж)
#   namespace — dict атрибутов и методов

🎭 Кастомный метакласс

Метакласс перехватывает создание класса и может его модифицировать.

class UpperAttrMeta(type):
    """Все атрибуты Becomes UPPERCASE."""

    def __new__(mcs, name, bases, namespace):
        upper = {}
        for key, value in namespace.items():
            if not key.startswith("_"):
                upper[key.upper()] = value
            else:
                upper[key] = value
        return super().__new__(mcs, name, bases, upper)

class MyClass(metaclass=UpperAttrMeta):
    greeting = "привет"
    count = 42

obj = MyClass()
print(obj.GREETING)  # привет
print(obj.COUNT)     # 42

👑 Singleton через метакласс

Гарантирует: только один экземпляр класса.

class SingletonMeta(type):
    _instances = {}

    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]

class Database(metaclass=SingletonMeta):
    def __init__(self, url):
        self.url = url

db1 = Database("pg://localhost")
db2 = Database("sqlite://:memory:")
print(db1 is db2)  # True — тот же объект!

🔌 Автоматическая регистрация плагинов

_registry = {}

class PluginMeta(type):
    def __new__(mcs, name, bases, namespace):
        cls = super().__new__(mcs, name, bases, namespace)
        plugin_name = namespace.get("name")
        if plugin_name:
            _registry[plugin_name] = cls  # автозапись!
        return cls

class JsonPlugin(metaclass=PluginMeta):
    name = "json"  # автоматически попал в _registry

print(_registry)  # {'json': <class 'JsonPlugin'>}

🔄 __init_subclass__ — современная альтернатива

Python 3.6+ позволяет обойтись без метакласса для простых случаев.

class Base:
    registry = {}

    def __init_subclass__(cls, plugin_name="", **kwargs):
        super().__init_subclass__(**kwargs)
        if plugin_name:
            Base.registry[plugin_name] = cls

class FastJson(Base, plugin_name="fast_json"):
    pass

print(Base.registry)  # {'fast_json': <class 'FastJson'>}
Правило: Начни с декоратора. Не хватает — __init_subclass__. Всё ещё не хватает — метакласс.

Metaclasses

__init_subclass__

• Проще и понятнее
